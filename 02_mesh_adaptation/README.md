# Triangular mesh adaptation

Own the scientific description, verification cases and evidence for the existing anisotropic adaptation method. No implementation has been imported. Its actual mathematical operations and capabilities will be established from the supplied work, not inferred from a candidate feature list.

Future inputs are triangular meshes, solution fields and explicit adaptation controls. Outputs will be adapted triangular meshes, quality/complexity measures and numerical verification evidence. Keep solver/case details outside the algorithm's numerical core.

Implementation will have one importable source location, as described in [software ownership](../docs/workflow.md), rather than copies in Euler and RANS directories. Preserve original work and rights; do not extend element support or replace the method without justification.
