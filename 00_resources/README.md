# Documentary resources

Own bibliographic metadata, verified links/DOIs, original research notes and resources with established redistribution rights. No scientific reference collection has been imported yet.

Inputs will be primary literature, theoretical material, technical documentation and experimental source descriptions. Outputs will be traceable references and original summaries supporting all later stages. Actual experimental data processing belongs to [06_experimental_validation](../06_experimental_validation/README.md).

Keep protected papers, teaching notes and uncertain-rights originals outside this checkout. Assign a stable identifier when recording a real public reference; map that identifier to its external local file in ignored `local/resource-paths.tsv` when needed. The local mapping format is two tab-separated fields: reference identifier and external file path. Do not publish that map, invent references or add source documents before rights review. See [publication workflow](../docs/workflow.md).
