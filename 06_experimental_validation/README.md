# Experimental validation and literature comparison

Own comparisons between numerical predictions and experimental evidence, including provenance, physical-condition matching, uncertainty and discrepancies. No dataset or validation result exists yet.

Future inputs are approved numerical results and traceable experimental sources referenced through [00_resources](../00_resources/README.md). Distinguish source data from digitized, extracted or otherwise transformed data; document units, conventions and processing, and verify redistribution rights before importing sources.

Outputs will be reproducible pressure/aerodynamic/shock-location comparisons, quantitative errors, uncertainty discussions and scientific figures/tables. Generic processing belongs in shared code; this stage owns comparison-specific choices and evidence. Generated outputs belong under root `outputs/`. Physical validation must not be inferred from code verification or numerical convergence alone.
